# Contributing

## Setup

```bash
npm install
npm run build
npm test
```

Run the TUI:

```bash
npm run dev
```

## Rules

- Don’t commit secrets (`~/.voxiva`, `.env`, keys).
- Keep the TUI lean — no duplicate status text.
- `npm test` should pass before a PR.

## PRs

Short description + how you tested (TUI snapshot or manual).
